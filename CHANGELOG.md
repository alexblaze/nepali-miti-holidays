# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html). New holiday years are released as minor versions.

## [1.0.0] - 2026-10-02

### Added

- Public holidays for BS 2083 from the Nepal Gazette (Rajpatra) Vol. 75, No. 67, Part 5, 2082-11-18:
  45 entries across national, community, regional, Kathmandu Valley, women, education, disability and
  offices-open observance scopes.
- `isHoliday`, `getHolidaysOn`, `getHolidays`, `getUpcomingHolidays`, `getHolidayYears`, `getHolidayYear`.
- `setHolidayDates` and `registerHolidayYear` for announced dates and new years; `resetHolidayData`.
